静态站点没有后台数据库，并不代表源文件天然安全。尤其在 GitHub Free + Pages 路线中，公开仓库里的内容可以绕过网站界面直接查看。

## 发布前检查清单

- [ ] 是否包含真实姓名、联系方式或精确位置？
- [ ] 是否引用了未经同意的聊天记录、会议记录或他人作品？
- [ ] 图片的文件名、EXIF 或截图区域是否泄露信息？
- [ ] 被过滤掉的笔记是否仍然存在于公开 Git 历史中？
- [ ] 附件是否因为路径规则而被意外发布？
- [ ] 是否含有 API 密钥、访问令牌或内部链接？

> [!danger] 构建过滤不等于源文件保密
> `publish: false` 或缺少 `publish: true` 只能阻止页面进入生成结果。若文件已经提交到公开仓库，任何人仍可在仓库中阅读它。

## 原型采用的规则

本项目启用了显式发布：只有 frontmatter 中包含 `publish: true` 的 Markdown 文件才会生成页面。实际迁移私人 vault 时，仍应使用独立的公开目录或导出流程。
