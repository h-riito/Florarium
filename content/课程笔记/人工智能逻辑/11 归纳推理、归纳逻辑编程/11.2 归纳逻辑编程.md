
归纳逻辑编程 ILP 是一种机器学习技术。我们用一个例子来理解。

假设你需要教一台计算机学习“祖父”这个概念。于是，你需要先提供一组被你打了“祖父”标签的例子，一组被打了“不是祖父”标签的例子，告诉计算机这些例子中哪些是，哪些不是：$$E_{\text{grandpa}}=E_{\text{grandpa}}^+\cup E^-_{\text{grandpa}}$$这被称为**正例**和**负例**。它们可能是这样给出的：

```
grandpa( A, B )+
grandpa( C, D )+
grandpa( A, D )-
```

以及，计算机需要一些**背景知识**，这些不需要学习，计算机已经知道，记作 $B$ 。

```
parent( A, E )
parent( E, B )
male( A )
male( E )
...
```

利用这两个输入，计算机尝试用算法找到一套假说 $H$ ，它能够尽可能符合给定的正例和负例：

```
H:grandpa( X, Y ):
	parent( X, Z ),
	parent( Z, Y ),
	male( X ).
```

我们希望的结果是，计算机拿着自己总结出的假设 $H$ ，配合背景知识 $B$ ，能够自己正确推导出 $E$ 中的正负例子，即$$B\cup H \vdash E$$
显然，得到的 $H$ 未必总是能完成上述任务，或者由于一些潜在的例子错误、模糊性等等，不可能满足所有的例子。为此，需要提出一种衡量 $H$ 好坏的指标。这种指标称为**损失函数**：$$\text{loss}(B\cup H, E)$$损失函数的具体表达取决于你希望的 $H$ 特点。一般来说，我们都会纳入这些指标：
1. 错误涵盖了多少负例（假阳性）；
2. 错误遗漏了多少正例（假阴性）；
3. 规则是否过于复杂（例如直接返回了一个映射表格而没有使用给定的基本规则来建立）。

我们说一个假设 $H$ **完全的**，如果它成功覆盖了所有正例；说它是**一致的**，如果它成功摒弃了所有负例。
