
### 构成基本 RS 触发器

考虑如何把 555 当作基本 RS 触发器来用。这很简单，因为它本身核心组成就是 RS 触发器。只需把⑥和②抽出作为 R 和 S ，其它引脚不用即可。注意通常在⑤脚过一个电容接地，用来确保参考电压稳定。

### 构成多谐振荡器

**多谐振荡器**在电源接通的情况下，预期输出矩形波，即要求前后沿都很陡的、来回切换状态的电路。

![[Pasted image 20260611134827.png]]

它的思想非常巧妙，总结来说就是利用⑦放电引脚来给一个电容充电，并让这个电容来抬升输入端的电压，从而自己振荡。

首先假设②和⑥的电压都很低，电容没有充电。那么这时复位无效，置位有效。根据电路连接，这时 MOS 管截止，⑦会开始对电容 C 充电。

由于②和⑥都被放在电容 C 的电压上，因此充电会同步抬升两个输入端的电压。

一直抬升，然后超过了 1/3 VDD 。这时，两者均没有生效，因此输出没有变化。然后超过了 2/3 VDD ，这时高电平复位生效。那么放电端⑦的 MOS 导通，向地放电，从而充电停止，电容 C 开始掉电。

那么这样输入端的电压又会开始下降。直到降低到 1/3 VDD 以下时，低电平置位又会生效，重新开始充电。

这样如此循环，大致变化规律如下所示：

上面曲线是输入端的电压变化曲线，下面是③脚输出的电平曲线。这样就形成了一个矩形波。


现在我们想要知道振荡周期怎么算。一个周期由上升和下降两部分组成，每个部分充电都是一阶响应的。过程省略，得到$$T=T_{1}+T_{2}=(R_{1}+2R_{2})C\ln 2$$这里充电/高电平过程等效电阻是 $R_{1}+R_{2}$ ，放电/低电平过程等效电阻是 $R_{2}$ 。因此，占空比就是$$D=\frac{T_{2}}{T}=\frac{R_{1}+R_{2}}{R_{1}+2R_{2}}$$

> [!NOTE] 计算电容充放电时间
> 计算电容充放电的时间，通式是这样的：$$t=RC\ln X$$这里电容和电阻就是电路中充放电电路中等效的电容和电阻，$X$ 表示一个比值，可以理解为$$X=\frac{\text{起始时刻驱动压差}}{终止时刻驱动压差}$$例如对于上面的例子，假设从 1/3 VDD 充电到 2/3 VDD ，那么起始时刻压差是 2 份 1/3 ，终止时刻是 1 份 1/3 ，比值就是 $2$ 。
> 



现在考虑怎么改变占空比。由于已经确定占空比完全由外部两个电阻大小关系确定，因此我们只需改造外部连接的两个电阻，而不需要动 555 内部的结构。一种可能的经典改法是把充放电的电阻回路分开，用变阻器控制：

![[Pasted image 20260611141243.png]]

这里充电时等效电阻是 $R_{1}+R'_{w}$ ，放电时等效电阻是 $R_{2}+R''_{w}$ ，通过控制 $R_{w}$ 占比即可改变占空比，同时保持周期总时长为 $T=(R_{1}+R_{2}+R_{w})C\ln 2$ 不变。



另一种改法是将充电和放电的电容分开：

![[Pasted image 20260611141822.png]]

这里充电由 $C_{2}$ 负责，放电由 $C_{1}$ 负责。这里的时间控制是这样的：每次充电/放电时，两者都是同时在进行的，但是有一方很快，另一方比较慢，从而由慢者控制时间。

例如，对于充电阶段，⑦看作断路，这时 $C_{1}$ 想要充电，距离电源只有 $R$ ，很快就会充好，而 $C_{2}$ 想要充电需要经过 $R_{2}+R_{w2}$ ，后者会设计成明显大于前者，这样充电就由 $C_{2}$ “拖慢速度”。

对于放电阶段，⑦看作接地，这时 $C_{2}$ 想要放电，经过二极管直接就放掉了，速度很快；但是 $C_{1}$ 需要 $R_{1}+R_{w 1}$ 才能放掉，速度明显慢于 $C_{2}$ 。

![[Pasted image 20260611142404.png]]

需要注意的是，根据这里的电路设计，因为充放电由两个电容分别负责，因此各自一个周期内的动作是从 0 充电到 2/3 VDD 或者从 VDD 放电到 1/3 VDD ，而不是像普通接法那样在 1/3 VDD 和 2/3 VDD 之间振荡，因此它的周期算法是$$T=(R_{2}+R_{w 2})C_{2} \ln 3+(R_{1}+R_{w 1})C_{1}\ln 3$$这里是 $\ln 3$ 而不是 $\ln 2$ 。



现在考虑怎么**改变生成的矩形波的频率**。这需要我们改变充放电的速度，这个速度可以通过改变参考电压来实现。我们说过通常⑤脚是 2/3 VDD 的参考电压，但是你可以向其加压，这样就可以改变振荡频率。具体来说，如果现在$$V_{⑤}=V_{C}\neq \frac{2}{3}V_{DD}$$那么接下来电容电平的振荡范围就是$$\left( \frac{1}{2}V_{C},V_{C} \right)$$也就是说，现在高低触发端将会和你在⑤脚上施加的电平以及它的一半进行比较。那么通过减小这个输入的电平，振荡区间就会变小，同时充放电压差也会改变，从而振荡加快。

考虑如何实现**单稳态触发器**。单稳态触发器的特点是电路需要触发信号，当没有触发信号输入时，电路一直处于稳定状态；一旦触发，立刻进入暂稳态，触发消失后维持一段时间，然后回到稳态。 

![[Pasted image 20260611144022.png]]

⑦脚放电仍然接上拉，然后反馈到⑥高触发端。但不接②低触发端。②用来接输入。

这里右侧的 RC 属于定时元件，用来控制从暂稳态返回稳态前持续的时间；左侧这里的 $C_{d},R_{d}$ 是微分电路。

左边这里的微分电路是这样的：
1. 首先假设输入是高电平，电容初始没有电压差，左右电压相等。
2. 输入突然做了一个跳变低电平。那么因为电容上的电压不会突变，因此电容右边也会立刻跳到低电平。
3. 但是由于右边经过 $R_{d}$ 接电源，因此电源会对电容充电，并重新让电容右侧达到电源电压。但这时电容左侧是低电平，因此这里出现一个充电尖峰，并且充电终点是电源电压，和之前一样大。
4. 然后输入重新变成了高电平。那么这个突变会导致电容的右边想要变成 2 倍电源电压。但是由于二极管的存在，这个跳变不会跳太高，最多只能跳到 VDD 加上二极管压降。这个“放电”是二极管完成的，所以没有逐渐的说法，跳变观察到就是只能跳一点点。
5. 最终放电到 VDD 大小。

上面描述了低触发端上的工作过程：**一旦输入出现一个负边沿，那么就会将低触发端使能一次**（电容右侧电平会向下掉到 0 再回升）。但输入处于低电平的时长和这个系统没有关系。

然后看输出。输出端初始时假定处于低电平，电容处于接地状态，保持不变。然后，由于输入端的低触发端使能一次，这次使能会导致输出变成高电平。那么⑦就截止，电容被电源充电。直到这个电压充电到 2/3 VDD ，就将高输入端使能，然后输出又被复位，重新回到 C 接地的状态。

因此，总体上这里的效果就是：每次输入出现负边沿时，输出就给出一个固定时长的脉冲，然后重新保持低电平不变，等待输入端下一个负边沿出现。这里的各个电平变化是这样的：

我们把这里放电的 $t_{re}$ 叫做**恢复时间**。一般来说要等 3 到 5 个 $\tau$ ，即$$t_{re}=(3∼5)r_{ds}C$$这里的电阻是 MOS 管的沟道电阻。



现在我们希望计算脉冲宽度 $t_{w}$ 。我们说脉宽完全由右侧的 RC 决定，这里充电是从 0 充电到 2/3 VDD ，所以脉宽就是$$t_{w}=RC\ln 3$$但是这种电路有一个缺陷是，在已经进入一次触发的过程中，不能再次触发，否则电路工作状态就混乱了。


因此提出**可重触发的单稳态触发器**。它更接近于自然逻辑：任何时候都可以一直按下输入来重复触发，每次重复都更新持续时间到最新按下起点。

把右边改装成经典的恒流结构。那么这时如果恒流大小为 $I$ ，可以列出充电满足的关系式：$$\frac{2}{3}V_{\text{DD}}=\frac{1}{C}\int_{0}^{t_{w}}I\text{ d}t$$从而 $$t_{w}=\frac{2}{3}\cdot \frac{V_{\text{DD}}C}{I}$$
