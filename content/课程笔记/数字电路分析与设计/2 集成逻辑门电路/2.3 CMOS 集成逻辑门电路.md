
CMOS 集成逻辑门电路顾名思义，就是用 NMOS 管和 PMOS 管组成的逻辑门电路。由于它性能在各方面都比 TTL 逻辑门优越，现在主流集成电路产品使用的都是 CMOS 门。



### 常见的 CMOS 逻辑门

要理解各种 CMOS 逻辑门，首先理解其中最基本的非门运作原理。一个典型的 CMOS 非门如下所示：

![[Pasted image 20260404163300.png]]

一个 CMOS 非门总是对称地包含一个 NMOS 管和一个 PMOS 管，且习惯上由于高电平在上，地在下，我们通常把 PMOS 画在上面，NMOS 画在下面。

你可以看到它们的接法非常简单且对称。事实上，它的工作原理考虑起来也很简单且对称。分析 CMOS 非门工作状态时，我们通常采用下面的假设：
1. 两管都是要么导通，要么不导通，暂时忽略其中导电沟道微导通的情况；
2. 两者完全对称，导通电压相同， $|V_{\text{TN}}|=|V_{\text{TP}}|$ 。
3. 两者导通电压之和小于提供的电源电平 $+V_{\text{DD}}$ 。

这样一来，考虑它的工作就很简单：如果输入低电平，那么 N 管电位差小，P 管电位差大，N 管截止而 P 管导通，从而输出电压和 $+V_{\text{DD}}$ 同步；如果输出高电平，那么 N 管电位差大，P 管电位差小，P 管截止而 N 管导通，从而输出电压和地同步。

由于 CMOS 管的两管总是一个导通另一个不导通，因此从电源到地的通路上的电流几乎不计，静态功耗很低。




在此基础上，我们看 CMOS 与非门。CMOS 与非门的结构特点是：两个输入各自有一组 CMOS 非门，且它们的 P 管并联、N 管串联。

![[Pasted image 20260404164029.png|457]]

由于 N 管串联，因此只要有一者让 N 管截止，对地就截止；由于 P 管并联，因此只要有一者让 P 管导通，对电源就导通。因此，这样的接法就实现了与非门功能：只要 A 和 B 中有一者为低电平，那么就会使得一个 NMOS 截止和一个 PMOS 导通，从而输出为高电平；只有 A 和 B 均为高电平时，所有 NMOS 导通而所有 PMOS 截止，输出为低电平。



CMOS 或非门刚好相反，PMOS 串联而 NMOS 并联。这时，只要输入一个高电平，那么就有一个 NMOS 导通和一个 PMOS 截止，从而输出为低电平；只有所有输入都是低电平，所有 PMOS 导通而所有 NMOS 截止，从而输出为高电平。

### 集成 CMOS 门的主要特性

相比 TTL 门，CMOS 门的特性非常接近于理想开关的特性，即开门电平和关门电平都非常接近于 $0.5V_{\text{DD}}$ ：

![[Pasted image 20260404165116.png]]

![[Pasted image 20260404165132.png]]

而且可以看到，它的高低电平基本等于电源电平和地电平，不存在压降的问题。

![[Pasted image 20260404170237.png]]

可以看到，CMOS 的电流不论在哪种工作状态下大小都比较小。静态功耗为零，动态功耗产生的原因是在切换状态时存在两管均微导通的情况，这时会放大电流，不过由于时间较短因此并不会产生太大的功耗。



还有一种基本构成方式称为 **CMOS 传输门**，也称为 **TG 门**。它的结构如下：

![[Pasted image 20260404190027.png|491]]

仍然是上下一组对管，但连线方式不同：漏极和源极均分别对应相连，衬底分别接电源和地，栅极分别接到同一个控制信号的两相上。输入从源极接入，输出从漏极接出，输出对地接大电阻。

当控制信号取高电平时，那么 PMOS 管上面是低电平，下面是高电平，电场有效；同时下面的 NMOS 管上面是低电平，下面是高电平，也是电场有效。那么这时，只要输入端给出一个电平，不论高低，总是至少会有一边的 MOS 管导通，并且当电平为中间值时，两个沟道都会导通，从而输出跟踪到输入电平。

当控制信号取低电平时，PMOS 管上下都是高电平，NMOS 管上下都是低电平，电场无效，无论输入如何都不导通，输出通过大电阻接地，相当于高阻态。

要注意 TG 门的两个控制端输入接的是同一个控制信号的两相，因此不可能出现都为高电平或者都为低电平的情况。

值得一提的是，TG 门的传输特性并不局限于高低电平，输出电平实际上可以跟踪输入电平，也即**它可以传输模拟信号**。不过控制信号通常只取分立的高低电平值，即 $+V_{\text{DD}}$ 或者 $0$ 。
