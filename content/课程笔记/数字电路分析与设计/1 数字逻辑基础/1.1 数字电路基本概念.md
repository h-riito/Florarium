
## 1 数字信号与数字电路

数字信号是指时间和幅度上都离散的值，而模拟信号是指时间和幅度上都连续的值。在生物医学信号处理中我们还提到离散信号，离散信号的时间上离散，但幅度上连续。这里我们的讨论对象是数字信号。

模拟电路主要研究的是模拟信号的放大和处理，因此它强调信号的不失真以及绝对大小。而数字电路着重研究输出信号和输入信号之间的逻辑关系，相对于模拟信号而言，不需要那么强调信号的不失真性，只需要区分高低电平即可。

数字化信号的优点在于：
1. 便于以各种形式存储、传输；
2. 抗干扰能力远远强于模拟信号；
3. 与模拟信号相比数字信息更容易扩展。

但最大的代价也在于损失了精度。

为了充分利用数字系统的处理能力，我们希望输入端的外部尽可能早地转换成数字信号，并在输出端尽可能迟地转换为模拟形式。

一个很好的例子是，有线耳机与蓝牙耳机。通常的 3.5mm 接口有线耳机的这条线传输的是模拟信号，这就要求线上有较强的抗干扰能力，否则就有杂音。而蓝牙耳机是将数字信号发送到耳机内再变为模拟信号，因此基本无需考虑干扰问题。

数字电路中，数值是通过二进制来传输的，这我们已经非常熟悉了。熟练掌握下面这张数制换算表，作为口算训练：

![[Pasted image 20260309203520.png]]

从十进制整数转换到 r 进制整数还有一个便捷的方法，那就是**除 r 取余法**。不断除以 r ，每次得到的余数就是转换后数从低到高每一位的数码，第一个余数是最低位 LSB ，最后一个余数是最高位 MSB 。

对于有小数的处理，只需完全相反，采用**乘 r 取整法**，将小数部分不断乘以 r ，每次都把溢出到整数的数作为一位数码，直到乘尽。

例如，将 $(10.125)_{10}$ 转换为二进制数。
1. 首先对整数部分转换，得到 $(1010)_{2}$ 。
2. 再按照上面说的方法对小数部分进行转换，得到 $(.001)_{2}$ 。
3. 因此转换后就是 $(1010.001)_{2}$ 。

## 3 数字电路中的代码

用一组二进制数来代替某一个特定的对象，这组二进制数就是该对象的代码。

其中，我们称用四位二进制数编码十个十进制数字的编码系统为 **BCD 码/Binary Coded Decimal** 。注意，这里说的是编码，因此凡是能用十种不同的二进制组合表示的均是有效编码。由于四位二进制数本身有 16 个，因此存在各种不同的编码系统。

**有权码**和**无权码**：有权码是指用来编码的四位二进制数的每一位都有一个权值，它编码的结果由权值计算得到。例如，直接用二进制转换来表示 0~9 就是一种按照 8-4-2-1 来排布的有权码。或者，也可以用别的权值排列，例如 5-4-2-1 。找不到这种权值计算规律的码，就是无权码。

![[Pasted image 20260309205035.png]]

可以看到，在某些权下某些数值有不同的编码方式。实际上除了 8-4-2-1 码以外其他码都会遇到同一个数多种编码的问题。这是允许的，只要能表示十个数字。

右边的无权码实际上是通过 8-4-2-1 码 +3 得到的，因此称为**余三码**。

区分有权码和无权码的一个简单规律就是，凡有权，那么它的 0 必然是 0000 ，而无权码可以不是。

当我们说 BCD 码时，默认就是 8-4-2-1 码。

一种特殊的无权码是**格雷码**，这是一种编码 16 个数的码：

![[Pasted image 20260309205748.png]]

格雷码又称循环码，它的特点就是任意两个相邻的十进制数字，它们的编码也只会变化一位二进制数。这在实际纠错方面有一定优势。而且注意 15 和 0 也是符合“只变一位”的规律的，因此又称循环码。

我们会好奇它的构造规律是什么。格雷码的构造规律可以用下面的镜面法来理解：

![[Pasted image 20260309210042.png]]

假设有三位数字，从 000 开始。现在从最低位开始变一位，变成 001 。现在要变第二位了，这时**将低位做镜面排列**，复制一份，即①。然后接下来要变第三位，那么同样将低位做镜面排列，复制一份，得到②。以此循环，直到最高位也变换完毕。无论最高位是第几位，凡是通过这种构造得到的编码，最终必然符合格雷码特点。


除了格雷码以外，还有其他用于校验的方法。例如**奇偶校验码**。这种校验的方法是：（以奇校验为例）
1. 在原数码的最后添一位校验位。
2. 这位校验位上的数要使得整个数中的 1 的个数为奇数。例如，如果原数为 `1010 0110` ，那么就应该填上 `1010 0110 1` 。
偶校验类同。



### 数字电路中的正负数表示

即原码、反码、补码机制。

**原码**就是除了最高位表示符号以外，其他全部按照正常的二进制转换存储。例如，`-100 1010` 就是 `1100 1010` 。

**反码**的正数部分表示和原码相同，而负数是除了最高位表示符号以外，其他全部对原码取反。例如，`-100 1010` 就是`1011 0101` 。

**补码**的正数和原码相同，负数是将反码值再加 1 ，即 `-100 1010` 就是 `1011 0110` 。补码有以下特点：
1. 补码的补码就是原码。
2. 补码对于加减可以交换顺序。例如，求 $12-9$ 的补码，可以求 $12$ 的补码加上 $-9$ 的补码。事实上，补码的设计初衷就是让所有加减运算都可以统一为加运算，从而简化 ALU 的计算方式。

注意对于正数，原码、反码、补码都是一样的。只有是负数时才有上述规则。

如果我们把两个非门串联起来，并头尾相连，那么就形成了一个记忆电路；在此基础上，在两个非门的出口处引出两条线，这两条线就总是一正一反，且具有记忆功能。只要不断电，这个状态通过反馈作用啮合，称为**自锁**。

![[Pasted image 20260312140012.png]]

但这样有一个问题，那就是一旦这个电路记住了一位二进制数，这个记忆内容将不能被改变。我们想要实现的是，想要改变时可以写入状态，并在想要读出时读出其中记忆的状态。

因此，我们可以把其中的两个非门改成与非门，左右额外接入一个输入：

![[Pasted image 20260314145619.png]]

这时，我们改变 $\overline{S_{D}}$ 和 $\overline{R_{D}}$ 上的电平作为输入，观察输出的情况：
1. 给左 0 右 1 时，根据与非门特点，只要输入有 0 输出必为 1，那么可以确定左边的 $Q$ 是 1 。这个 1 反馈到右边，右边双 1 输入，从而右边输出 $\overline{Q}$ 为 0 。同时这个 0 反馈回左边不矛盾。
2. 给左 1 右 0 时，根据与非门特点，右边输出必为 1 ；那么左边输出就是 0 ；左边反馈回右边也不矛盾。
这样，我们就实现了以下特点：**给入一高一低电平时，同侧输出端的电平总是相反**。你可能会说，这有什么用，换成两个非门不是一样吗？别急，接下来就是它的用处体现的地方：
3. 如果两边都给 1 ，那么暂时没有确定的情况，根据对称性我们假设左边输出 $Q$ 为 1 ，那么右边输出就应该是 0 ，而这个 0 传回左边不矛盾。那么这就是一种合法状态；如果假设右边输出 $\overline{Q}$ 是 1 ，那么左边输出就应该是 0 ，并且这个 0 传回右边也不矛盾。也就是说，无论原来这组输出是什么状态，**输入给两个高电平时不会影响输出，输出保持记忆**。
接下来你肯定会想，如果两边都给 0 会怎么样。但这是不允许的。如果两边都给 0 ，那么两个输出都变成 1 。这虽然逻辑上没有问题，但这个状态会破坏我们前面说的记忆系统：当我们想再次维持记忆状态时，加入两个 1 作为输入，此时由于两个输出都是 1 ，会发生竞争性变化，最终是左 0 右 1 还是左 1 右 0 取决于两个门的速度快慢，而这是不确定的，从而会丢失记忆。因此我们不把双 0 输入纳入到系统中。

为了让这个系统更好理解，我们这样描述它：$Q$ 和 $\overline{Q}$ 代表输出，它们总是相反，因此我们只看 $Q$ 作为语义理解；$S_{D}$ 的意思是 set ，而 $R_{D}$ 的意思是 reset 。set 操作是让输出 $Q$ 变为高电平 1 ，而 reset 操作是让 $Q$ 重新变为 0 。当 set 和 reset 上面有取反时，表示这个输入要低电平才生效，否则默认高电平生效。从而，对于 NAND 构成的 RS 触发器：

| set 输入 | set 端语义 | reset 输入 | reset 端语义 | 结果 Q |
| :----: | :-----: | :------: | :-------: | :--: |
|   0    |   生效    |    1     |    无效     |  1   |
|   1    |   无效    |    0     |    生效     |  0   |
|   1    |   无效    |    1     |    无效     |  维持  |

这样它的意义就比较明确：set 生效而 reset 不生效时，结果为 1； 反之为 0；都不生效时结果维持；不允许同时生效。

我们也可以将其改成或非门，得到 NOR 构成的 RS 触发器：

我们说的锁存，实际上是指在输入和输出之间加一个“跟踪控制”。通过跟踪控制来达到两种工作状态：一种是让输出跟踪输入，就和直接连接或者经过非门连接一样；另一种是锁存，即不管输入，维持当前输出不变。
