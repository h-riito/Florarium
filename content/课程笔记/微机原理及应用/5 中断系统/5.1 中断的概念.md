
**中断**是指允许通过外部某事件的发生来暂时停止 CPU 原本执行的操作，并转而先处理中断程序的机制。这种机制的引入使得监控中断发生事件这一操作不需要写在 CPU 的主循环中，以此让 CPU 得以专心做原本的工作，等到中断事件发生后再处理相关任务。

引起中断发生的来源称为**中断源**。它可以是：
1. 外部设备发生输入；
2. 通讯时一次发包完成；
3. 定时器倒计时结束；
4. 电源发生断开；
上面这些事件都可以作为中断的条件。容易想到，如果没有中断机制，那就需要分支控制来持续监控事件的发生状态，这会让程序变得非常低效且冗长。


中断机制类似于子程序调用，但具备更多特性。
1. **中断的屏蔽和开放**：当中断关闭时， CPU 不响应发生的中断事件；
2. **中断的响应和返回**：类似于子程序；
3. **中断的优先级**：多个中断发生时，按照预设的顺序处理中断事件；
4. **中断的嵌套**：在中断程序中监听进一步的中断事件。
