
有时会需要实现下面这样的多状态计时：
1. 状态 0 计时 2 秒。
2. 结束后进入状态 1 ，计时 4 秒。
3. 结束后进入状态 2 ，计时 3 秒。

这种计时由于每种状态的时长不同，难以通过一个统一共用的计时器中断服务来完成，因为需要根据状态装填不同的初值。因此可以采用下面的办法：
1. **计时器中断服务或者子程序只负责计时的“最大公约数”**，例如上面的例子就是 1 秒。
2. 新增一个计时**状态切换子程序**，这个程序负责给**最外层的状态变量**装填不同初值。


举例来说，假定晶振频率 $12\text{ MHz}$ ，那么计时器单位为 $1\text{ }\mu\text{s}$ 。如果使用计时模式 2 ，那么可以单次计时 $250\text{ }\mu\text{s}$ ，采用两层循环变量，可以计时 $40\times 100\times 0.25\text{ ms}=1\text{ s}$ 。这两个循环变量由 `R6 R7` 担任。然后，再让 `R5` 担任最外层循环变量，分别取 `2/4/3` 。

这样一来，T0 中断服务只需要无脑执行自减重装，并且由于 `R5` 是最外层循环变量，不需要对其重装：

```
T0_Interrupt:

djnz    R7, T0_done
mov     R7, #100
djnz    R6, T0_done
mov     R6, #40
djnz    R5, T0_done    ;这里只要自减即可，无需考虑不同状态的重装

acall   Switch_Stage

T0_done:
reti
```

然后让 `Switch_Stage` 来负责重装和状态切换：

```
Switch_Stage:
inc      R0             ;假设状态在R0中
mov      A, R0
rl       A              ;缩放
mov      DPTR, #Jptb
jmp      @A+DPTR        ;散转

Jptb:
ajmp     case0
ajmp     case1
ajmp     case2
ajmp     case3

case0:
	mov    R5, #2
	jmp    case_done
	
case1:
	mov    R5, #4
	jmp    case_done
	
case2:
	mov    R5, #3
	jmp    case_done
	
case3:
	;这里写用于处理R0状态溢出时的处理，例如循环回0或者跳出计时
	
case_done:
mov    R6, #40
mov    R7, #100
ret
```
