
一台计算机，通常是微型计算机，都应当由下面几个部分组成：
1. CU/控制器；
2. ALU/运算器；
3. Memory/存储器；
4. 输入输出/IO；
其中，CU 和 ALU 都被包含在 CPU/中央处理器中。

下面是关于数据存储单位的常识介绍：
1. **位/bit** ：一个 bit 是一个二进制数位，是数据的最小单位。
2. **字节/Byte** ：一个字节是指 8 个位。一般以字节作为衡量有意义存储信息的基本单位。
3. **字/word** ：不同计算机对于字的定义不同。在 51 单片机中，1 字是指两个字节，即 16 位。
4. **双字/double word** ：不同计算机对于双字的定义也不同。在 51 单片机中，1 个双字是指两个字，即 32 位。

关于存储器，需要了解下面的常识：

**存储器 memory** 是指存储数据的硬件设备。一般来说，一个存储器由四个部分组成：**存储矩阵、地址译码器、读写控制、三态双向缓冲器**。

程序存储器 ROM/Read Only Memory 是用来储存计算机执行程序的存储器，它的设计初衷是固定这台微机的基本程序和功能，不接受写入。最传统的 ROM 是以掩膜编程的只读存储器，后来出现了 PROM/OTP/One Time Programmable，允许对其写一次的 ROM ；后来出现了 EPROM/Erasable Programmable ROM，即可擦除、可编程的 ROM。这时，虽然名为 ROM ，但实际上已经允许擦写了，只是这时的擦除需要通过紫外线照射完成，没有通常意义上的读写那样方便。再后来出现了 EEPROM ，这个 E 代表 Electric ，即可用电擦写。以及再后来又有了 Flash/闪存等等存储器形态。

数据存储器 RAM/Random Access Memory 是用来存储数据的存储器，它是可擦写的，同时一般也是易失性的，即必须接通电源来维持数据存储。RAM 可以分为两类，其中，静态 RAM/SRAM 访问速度非常快，但缺点是比较占晶体管面积，因此它一般只用在 CPU 旁边。为了解决 SRAM 对硅片的占用，发展出了一类动态的 DRAM 。DRAM 的实现方式是一个个小电容，而电容器要想维持数据就必须不断刷新。与之相对地，SRAM 在数据存入后不需要进行额外的操作来维持数据存在，只要有电源接通即可。DRAM 因此读写速度不如 SRAM 。有时我们也听说 SDRAM ，这里的 S 代表 Synchronize ，即同步。同步的意思是用时钟进行时序控制。SDRAM 中的一个常见的分支就是 DDR ，我们购买内存条时经常听说 DDR4 DDR5 甚至 DDR6，这些数字代表不同的产品代际，但它们的 DDR 这个名字的意义是一样的，即 Double Data Rate 。很多受到时序控制的元件工作方式都是在时钟脉冲的上升沿或者下降沿之一进行一次操作，而这里 double 的意思就是在上升沿和下降沿都进行操作。这里具体在数电课程中会讲。

现在我们常说的内存一般都是用 RAM 实现的，而存储则是 HDD/机械硬盘或者固态硬盘。HDD 的成本最低，但在硬盘种类里也是读写速度较慢的。


在计算机中，数据的通信通过总线系统完成。总线通常有三种，分别是地址总线 Address Bus ，数据总线 Data Bus ，控制总线 Control Bus 。总线相当于是信息传输的介质，要理解总线的必要性以及其工作方式，只需要想象这样的类比：当教师在课堂上讲课时，教师中的空气传播声音，空气就可以看作一个总线。如果 CPU 现在对存储器中某个地址发出读指令，就好比教师想要点名某个学生回答问题。这个点名和其他学生无关，因此其他学生不会接收这个点名命令，即对总线保持高阻态，避免错误接收指令；教师和被点名学生作为主端和从端则接入总线进行通信。而当学生开始回答时，回答内容通过数据总线回到 CPU 。
