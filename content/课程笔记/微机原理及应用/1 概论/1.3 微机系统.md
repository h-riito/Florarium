### 微机硬件组成

可以看到，微机只是微机系统的硬件部分中的一个核心。硬件部分除了前面说的 CPU、RAM、I/O、总线之外，还包括必要的外设、电源、机箱等等。而在硬件系统之外，还包括软件系统。

如果我们不细究 CPU、RAM 这些模块的构成，那么微机系统的硬件部分可以简单表示为下面的结构：

![[374a7e3b080af07acaf1096082d34867.jpg]]

可以看到，硬件部分以 CPU 为核心，通过总线连接了 ROM、RAM、I/O 三个部分。顾名思义，CB、DB、AB 分别传输命令、数据和地址。其中，控制总线和数据总线都是双向的，而地址总线是单向的。CPU 不需要从外部获知地址，它只需要发送地址并获得数据或命令。

从外部模块的角度看，ROM 只接受控制、只接受地址、只发送数据。RAM 只接受控制，只接受地址，发送或接受数据。I/O 发送或接受控制，发送或接受数据，只接受地址。这很好理解，CPU 不需要接受来自 ROM 和 RAM 的控制，它们都是存储器；且其中 ROM 是只读存储器，不能输入数据。

一般来说，我们会在 ROM 里驻留系统软件，这样就达到了微机系统软件不可修改的目的。

每个模块接入总线时，都有**三态逻辑元件**来提供高电平、低电平、高阻的变化。根据接入总线的双向性，分为**单向三态缓冲器**和**双向三态缓冲器**。

![[8367858f190e007cf47dfac7c42df168.jpg]]

图中的小圆圈代表反相，TSC/Three State Control 为**三态控制端**。凡 TSC 能使元件通过 D 传来的信号时，D 的变化就能使得 Y 变化；凡 TSC 让元件高阻时，D 无论如何 Y 都断开。具体来说：

1. （a）中 TSC 为 1 时高阻，TSC 为 0 时，Y 跟随 D 。
2. （b）中 TSC 为 0 时高阻，TSC 为 1 时，Y 跟随 D 。
3. （c）中 TSC 为 1 时高阻，TSC 为 0 时，Y 反相于 D 。
4. （d）中 TSC 为 0 时高阻，TSC 为 1 时，Y 反相于 D 。

三态双向缓冲器就是两个不同方向的单向缓冲器并联，这样就有两个 TSC ，分别控制来去的跟随情况。


### 微机软件系统

##### 程序设计语言

程序设计语言分为**机器语言**、**汇编语言**、**高级语言**。机器语言是直接用二进制指令代码记录的程序语言，它可以被计算机直接理解，因此执行速度快。但是很显然它难以被人类理解，因此运用起来非常困难。汇编语言用有一定语义的助记符来代替操作指令，这使得它不仅保留了和机器语言的一一对应性，还具备了一定程度的可读性。然而，汇编语言是高度面向机器的，必须深入了解一种机器的具体设计才能利用其指令系统完成编写，因此迁移性差。而高级语言舍弃了和机器码的一一对应性，大大提升了可读性，并引入编译的概念，避免了程序代码和机器设计强相关，是对人类理解最便捷的语言。相对地，高级语言编写的程序必须有编译器/解释器才能够让机器运行。

**系统软件**是用来提高计算机使用效率、增加功能、简化程序设计、方便用户的一类程序，包括操作系统、监控程序、诊断程序等等。

**应用软件**是指用户利用计算机各种程序设计语言和计算机系统软件编制的，用来解决用户实际问题的程序。



### 衡量计算机性能的主要技术指标

通常采用下面几种指标来认识一种计算机：
1. **字长**。字长是指这台计算机的**运算器一次性可以处理的二进制位数**。字长越长的计算机，其有效位越多，计算精度越高，速度越快，但硬件性能开销越大。认识下面几个单位的意义：8 个二进制位称为 1 个**字节 byte/B** ；2 个字节称为 1 个**字 word/W** 。常常也把 32 位二进制数，也就是两个字定义为**双字 double word/DW** 。注意字和双字都是 51 单片机中的概念。现在常见的处理器通常都是 64 位的，一些老处理器则是 32 位的。
2. **存储容量**。存储容量反映存储器能存储多少二进制信息。我们已经熟悉各种数据量单位。对于微机而言，高档微机一般具有 128MB 以上的内存以及 30GB 以上的外存。
3. **指令系统**。指令系统是计算机所有指令的集合。
4. **指令执行时间**。指令执行时间取决于计算机的主时钟频率、CPU 的体系结构等等。它还给出每条指令执行需要的机器周期数。
5. **外设扩展能力**。这衡量了一台计算机所能配接的外设的丰富程度。
6. **软件配置**。即系统软件的丰富程度。
