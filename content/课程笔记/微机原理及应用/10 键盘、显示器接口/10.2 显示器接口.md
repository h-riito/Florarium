注意到灯珠的实际亮度由电流决定。那么，如果是共阳极，最亮也是 5V 除以限流电阻。这时如果我们想要控制亮度，应该怎么实现呢？

可以通过 PWM 脉宽调制方法。简单说就是将亮起状态改成极快的频闪状态，然后通过调整频闪的占空比来控制人眼看到的亮度。


字符显示原理不讲了，实验课中涉及到很多次了。



当需要点亮多个字符时，最直接的办法自然是直接接在 P 口上。这样的好处是每个灯珠都是纯直流供电，亮度最强，缺点是占用大量 IO 口。

更常用的方式是用三总线扩展。每一位字符都接在一个锁存器上，这样实现静态显示，并通过片选改变要写入显示码的目标。




动态显示是不断扫描选通，那么这样每一位显示是闪烁呈现的。这在人眼看来没什么问题，但有一个问题是，如果我们采用的是 PWM 调光方案，那么现在你需要考虑多个扫描对象分时的问题。这里我们采用的模式通常是让每一位码的刷新都按照 PWM 分布，而不是在原本的 PWM 分布内把亮起时间切分成多个位。例如，假设每一位分配的时间是 1ms ，那么如果需要 60% 亮度，应该是让每一位亮起 0.6ms，熄灭 0.4ms ，而不是取 10ms ，在前 6ms 中刷新每一位而后 4 ms 保持全灭。

你可以想象，对于多位封装的数显，连接到主机有多种方法。最直接的方法是不按照通用 IO 扩展，直接接在 Pn 上。例如

![[Pasted image 20260621142027.png]]

这种接法下，位选和送显全部由你软件控制 P2 和 P0 实现。它的程序可以是这样的：

```
Play:
		mov    R0, #Display_Cache     ; R0 指向用于送显的缓冲区首地址
		mov    R1, #0FEh              ; 根据电路连接的位选初始值
		mov    R2, #8                 ; 每轮刷新计数器
		
Disp1:
		mov    A, @R0                 ; 从缓冲区取显示数
		mov    DPTR, #Display_Table   ; 准备从段码表查显示码
		movc   A, @A+DPTR             ; 查显示码
		mov    P0, A                  ; 显示码送数据线
		mov    P2, R1                 ; 位选码送位选线
		mov    A, R1                  ; 准备处理位选码
		rl     A                      ; 根据硬件，左移准备下一次刷新位置
		mov    R1, A                  ; 放回
		inc    R0                     ; 缓冲区读取头后跳
		acall  Delay                  ; 单次显示延时
		djnz   R2, Disp1              ; 计数器自减
		mov    P2, #0FFh              ; 一轮刷新完成，熄屏
		ret
```

这个程序比较基础，并且实际上存在一些问题：
1. 没有体现 PWM 调节功能。每一轮刷新中按顺序点亮的每一位，但没有控制每位具体点亮区间的功能。
2. 显示码处理不成熟。通常我们会让 `Display_Cache` 中存放的是直接可以用来送显的显示码，也即这部分应该在主循环完成，避免在送显中来执行。
3. 可能产生轻微重影，因为在每一位显示完毕后，没有关闭位选，这导致下一轮的送显在极短时间内会先送到上一位（考虑到这里先送显示码，后送位选码）。更好的做法是每轮确定完成当前位的显示后都全局熄屏一次，即给位选送 `#0FFh` 。



如果你认为这种方式占用 P 口太多，那么同样将其改成通用 IO 扩展标准接法。

首先，在这种接法下，主机应当把位选码和显示码的送出对象看作两个寄存器 `SEG_Port` `DIG_Port` 。此后要送码时，对这两个地址执行外部写操作即可。

我们假设地址安排如下：

```
SEG_PORT    EQU 8000H     ; 送显示码地址
DIG_PORT    EQU 8001H     ; 送位选码地址

DISP_BUF    EQU 30H       ; 显示码缓冲，从 30h 开始共 8 字节
DIG_BUF     EQU 38H       ; 位选码缓冲，从 38h 开始共 8 字节
SCAN_IDX    EQU 40H       ; 每轮扫描索引
```

每次刷新一位时，为了让显示稳定、可控，我们要遵循这样的标准：
1. 先关闭所有位选。
2. 写当前显示码。
3. 写当前位选码。

外部写操作为了语义清晰起见，可以先包装一层：

```
; 外部写显示码
Write_Seg:
        MOV     DPTR, #SEG_PORT
        MOVX    @DPTR, A
        RET

; 外部写位选码
Write_Dig:
        MOV     DPTR, #DIG_PORT
        MOVX    @DPTR, A
        RET
```

然后考虑用定时器中断来单独负责刷新，避免占用主循环。中断每次只刷新 1 位，通过前面设置的 `SCAN_IDX` 来控制具体是轮到哪一位。

```
Timer_ISR:
		; 保护现场
        PUSH    ACC
        PUSH    DPL
        PUSH    DPH
        PUSH    PSW

        ; 先熄灭全部（清空位选）
        MOV     A, #0FFH
        ACALL   Write_Dig

        ; 利用 SCAN_IDX 作为偏移量来取出缓冲区中对应的显示码
        MOV     A, SCAN_IDX
        ADD     A, #DISP_BUF
        MOV     R0, A

        ; 送显
        MOV     A, @R0
        ACALL   Write_Seg

        ; 利用 SCAN_IDX 作为偏移量来取出缓冲区中对应的位选码
        MOV     A, SCAN_IDX
        ADD     A, #DIG_BUF
        MOV     R0, A

        ; 送显
        MOV     A, @R0
        ACALL   Write_Dig

        ; 尾部处理：IDX 自增，并检查是否循环
        INC     SCAN_IDX
        MOV     A, SCAN_IDX
        CJNE    A, #08H, Timer_ISR_End
        MOV     SCAN_IDX, #00H

Timer_ISR_End:
		; 现场恢复
        POP     PSW
        POP     DPH
        POP     DPL
        POP     ACC
        RETI
```

这样送显循环逻辑非常清晰，主程序则只需要负责查表并向缓冲区写入想要显示的码值即可，无需考虑关于送显的问题。
