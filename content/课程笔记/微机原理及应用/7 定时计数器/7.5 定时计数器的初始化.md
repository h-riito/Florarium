
初值填写规则比较好理解：由于总是正计时，因此先计算定时的机器周期数量，然后让上限减去这个值就是初值。

例如，晶振 12MHz ，要求定时 0.5ms 。机器周期是 1us ，那么定时需要 500 次计数。这个值不能用 8 位定时器完成，因此必须使用方式 1 或 0 。如果以方式 1 ，那么上限值是 65536 ，初值就是 $65536-500=65036$ ，将这个数写在 `T0` 中即可。

如果采用方式 0 ，那么这里情况是这样的：我们**先忽略不使用的 3 位**：

```
1 1 1 1 0 0 0 0 xxx 0 1 1 0 0
```

按照计算出的二进制值**填写到这 13 位上**。然后，再**在这 3 位的位置上插入 0** （插入 1 也可以，因为反正不使用，但一般约定插入 0 ），得到的**新 16 位二进制值**就是我们要装填的值。


再看一个例子：晶振 12MHz ，要求用定时器 `T1` ，使用模式 0 ，让 `P1.0` 上输出周期 2ms 的方波。

输出方波，实际上就是翻转电平。方波周期是 2ms ，那么就是每 1ms 翻转一次。晶振 12 MHz ，对应一个机器周期是 1us 。那么就要计数 1000 次。据此完成 `T1` 的初值装填，不再赘述。

接下来设置 TMOD 寄存器。我们不使用外部控制启停，不使用计数器模式，工作模式是 0 ，因此给 `TMOD` 写一个全低即可。

![[Pasted image 20260518202522.png]]

具体代码可以这样写：

```
	mov    TMOD, #0      ; 全低
	mov    TH1, #0E0h    
	mov    TL1, #18h     ; 算出来具体要填的初值
	setb   EA            ; 允许中断总开关
	setb   ET1           ; 允许 T1 中断
	setb   TR1           ; 开始享受计时器 1
	sjmp   $             ; 坐等计时
	
	org    001Bh
	ljmp   BRT1          ; T1 中断入口，跳到服务程序
	
	org    0800h
BRT1:
    mov    TH1, #0E0h
    mov    TL1, #18h     ; 重装填
    cpl    P1.0          ; 翻转 P1.0 上的电平
    reti                 ; 返回
```
