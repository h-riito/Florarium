
同 7.5 中任务，但是使用工作模式 1 ，**不允许用自带的中断**，要求主动查询溢出标志 `TF1` 。

既然不让用中断，那么我们就在主程序反复查询 `TF1` 的状态，是高电平就去翻转电平。但是注意，这时一定**要手动把 `TF1` 清零**，因为不经过系统中断的话是不会自动维护的。

```
	mov    TMOD, #10h    ; 使用方式 1
	setb   TR1           ; 直接启动计时器

LOOP:
	mov    TH1, #0FCh    ; 
	mov    TL1, #18h     ; 赋初值
	jnb    TF1, $        ; 检查 TF1 ，如果不是高电平就原地跳转
	cpl    P1.0          ; 翻转 P1.0
	clr    TF1           ; 手动清除 TF1
	sjmp   LOOP          ; 回主循环
```

可以看到这种设计下第一个循环中计时长度是有问题的。但是这没关系，等第一个周期过后就可以正常工作。

注意这只是为了练习，这种用法不是我们推荐的。




下面看一种生产上常见的计数器应用。如图所示，用一个光敏电阻给工件计数，每次工件挡住光时，光敏电阻由于没有光就会阻值变大，从而经过三极管后在 `T0` 上产生一个高电平。我们的目的是每 100 个工件装一箱，即发出一个装箱命令，假定也是高电平。

那么，我们只需要将 `T0` 设置为计数器模式即可。并且，由于我们只需要数到 100 ，因此可以使用模式 2 ，这样省去了重装的步骤。同时，还可以用一个寄存器记录箱数。

初值计算省略，直接看代码：

```
	clr    P1.0           ; 初值设置为低电平，避免误触发
	mov    R5, #0      
	mov    R4, #0         ; R5R4 一共 16 位用来记录箱子数量
	mov    TMOD, #6       ; 根据前文所述给出的 TMOD 字
	mov    TH0, #9Ch 
	mov    TL0, #9Ch      ; 自动重装模式，两个都填一样的值
	setb   EA            
	setb   ET0
	setb   TR0            ; 启动启动启动，还有这个
	sjmp   $              ; 等待计数
	
	org    000Bh
	ljmp   COUNT          ; 中断服务跳转
	
	org    1000h
COUNT:
	mov    A, R4       
	add    A, #1
	mov    R4, A
	mov    A, R5
	addc   A, #0
	mov    R5, A          ; 到这里的部分都是计数，做了一个跨寄存器进位
	setb   P1.0           ; 发高电平
	mov    R3, #100       ; 准备给这个高电平一个软件延时
	
DLY:
	nop
	djnz   R3, DLY        ; djnz 是 2 个周期，nop 1 个周期，一轮 3 周期
	clr    P1.0           ; 高电平持续 300us ，然后变低
	reti                  ; 中断结束
```




下面看门控位 `GATE` 是怎么用的。假设我们要测量 $\overline{\text{INT1}}$ 上的一个高电平持续了多长时间。假定晶振频率 12MHz ，脉冲宽度不超过 65ms 。

它是怎么做的呢？我们让 $\overline{\text{INT1}}$ 来作为外部控制启停控制计时器，那么一旦高电平出现，计时器就开始工作。高电平结束时，计时器就停止。停止时，记录的长度存储在计时器内部。那么把这个值取出来就是宽度。

![[Pasted image 20260518205324.png]]

![[Pasted image 20260518205346.png]]

```
	mov    TMOD, #90h    ; 按照前文所述的状态字
	clr    TR1           ; 先别启动，可能一上来就是高电平
	mov    TL1, #0       ; 初值填 0 ，这样就尽可能长的测量空间
	mov    TH1, #0
	jb     P3.3, $       ; 先等 P3.3 确实是低电平
	setb   TR1           ; 然后允许检查外部控制
	jnb    P3.3, $       ; 这时等待高电平出现
	jb     P3.3, $       ; 出现后就等待低电平
	clr    TR1           ; 完成计数，关闭计时器
	mov    A, TL1        ; 取出 16 位长度
	mov    B, TH1
```

这里有一个比较容易混淆的点是， $\overline{\text{INT}}$ 虽然标注了非号，但是它只有在作为外部中断时是低有效，或者下降沿有效。**作为定时器门控时，它是高有效**。





还有一种用法是**把计时器当作外部中断**来用。如果默认的两个外部中断不够用，可以将定时器设置为计数器模式，持续侦测外部计数，并**让初值直接就是最大值**。这样一来，一旦外部计数触发，**立刻就进入中断**，实现外部中断效果。

```
	mov   TMOD, #06h   ; 用 8 位自动重装更方便
	mov   TL0, #0FFh
	mov   TH0, #0FFh   ; 直接填最大值
	setb  ET0
	setb  EA
	setb  TR0
```

这种方法相比于原装的外部中断，局限在于**只能响应下降沿中断**，而不能像真的中断一样有多种检测方式。
