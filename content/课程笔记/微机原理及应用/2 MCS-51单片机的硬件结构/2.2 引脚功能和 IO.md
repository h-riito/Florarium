图中 8 位 I/O 口管脚不再赘述，即 P0～P3；在剩下的管脚中：
1. $\text{V}_{\text{CC}}$ 和 $\text{V}_{\text{SS}}$ 即**电源管脚**，一个接电源，一个接地。
2. $\text{XTAL1}$ 和 $\text{XTAL2}$ 是**时钟管脚**，可以接一个晶振作为内部时钟，也可以接外部方波信号作为外部有源时钟：![[Pasted image 20260323110948.png]]一般来说采用内部时钟方式，因为不需要额外电源给时钟电路供电。
3. $\text{ALE/}\overline{\text{PROG}}$ ：**地址锁存允许输出管脚**（Address Latch Enable/Programming）。当地址总线有效时，配合这个管脚上的信号，可以把当前地址总线中的地址锁存在外部锁存器中。
4. $\overline{\text{PSEN}}$ （Program Store Enable）：**程序存储器允许输出端**。它负责发出对片外部 ROM 的选通。当它是低电平时，读取外部 ROM 上的内容。
5. $\overline{\text{EA}}/\text{V}_{\text{pp}}$ ：**片外 ROM 允许输入端**。当它是高电平时，可令 CPU 执行片内 ROM 指令（这也是为什么它有非号，表示低电平使能，高电平使不能）；当它是低电平时，CPU 只向片外 ROM 取指。不过，如果 PC 超过 4KB/8KB 时，片内 ROM 用尽，自动转向片外 ROM 取指。对于没有配备片内 ROM 的单片机（如 8031 ），这个管脚只能取低电平。
6. $\text{RST/V}_{\text{dd}}$ ：**复位信号输入端**。当它是高电平时有效，且**保持两个机器周期的高电平**即可完成复位。复位时，PC 回到 `0000H` 位置，即整个单片机会执行的第一条指令。其他寄存器也会重新被赋值，回到初始状态。


当一个 51 单片机开始复位时，寄存器会回到下面图表所示的状态：

可以看到，PC 回到第一条指令地址上，即 `0000H` 。因此，对于那些没有片内 ROM 的单片机，例如 8031 ，其外部扩展的 ROM 地址必须覆盖 `0000H` ，否则无法正常执行代码。比起 PC 的初值，其他寄存器的初值相对来说不那么重要，因为其他寄存器在使用前还有机会赋一个指定的初值。但 PC 必须在复位后就立刻指向 `0000H` 。
        

下面介绍 MCS-51 单片机的 I/O 口。它的输入输出通过 4 个双向 8 位口完成，也就是 P0、P1、P2、P3 。其中，P0 这一组引脚是**三态双向口**，其他三组是**准双向口**。所谓准双向口的意思是，它们的内部有一个集成的上拉电阻，而 P0 这一组中没有。**四组口读数前都要写全高**，原因是有端口锁存器，如果此前写过低，读引脚会读到该状态，则通过外部输入高不能将其拉到正确值。


### P0 口


P0 口是这 4 个 I/O 口中最复杂的一个口。编号 P0.0 ~ P0.7 分布在管脚编号 39~32 上。P0 口一共有三种功能：作为地址总线、作为数据总线、以及当这两者都不使用时作为通用 I/O 口。

![[d6288d1a16a27be0ac7c997aadf3f9ae.jpg]]

##### P0 作为地址/数据复用总线的情形

当 P0 口作为地址/数据复用总线时，它既可能是输入，也可能是输出。输出时，**控制端为高电平**，多路选择器 MUX 由控制信号决定，因此**接受到高电平时，开关向上打，接通地址/数据**这一路。那么，这时地址/数据线的信号经过一个非门，可以到达 T1 管。此外，上面地址/数据信号和控制信号经过一个与门后控制 T0 管。为了后续方便说明。我们把地址/数据这个逻辑变量用 AD 表示，控制信号用 C 表示。

现在，T0 的基极电平为 $\text{AD}\cdot\text{C}$ ，而 T1 的基极电平为 $\overline{\text{AD}}$ 。又因为现在我们分析的是 P0 输出工作状态，$\text{C}=1$ ，因此 T0 又可以等价为直接由 $\text{AD}$ 控制。所以，这时 T0 和 T1 之间总是一个截止一个导通的状态。如果 $\text{AD}$ 给高，那么 T0 导通而 T1 截止，P0 经过 T0 接电源，为高电平；反之则接地，为低电平。

总结上面的过程，得到：**当控制端给高时，地址/数据给高则 P0 为高，地址/数据给低时 P0 为低**。这就实现了输出的效果，地址/数据上的电平原样送达 P0 的引脚上。

当要输入时，**控制端会给低电平**。那么，MUX 会将开关向下打，和 P0 锁存器的 $\overline{\text{Q}}$ 接在一起。关于锁存器的特性，我们在数字电路中已经了解过。在这里表现为：当 $\text{CL}$ 给高时，将 $\text{D}$ 原样锁存到 $\text{Q}$ 上。当 P0 作为地址/数据复用总线时，无论它是输入还是输出，系统都会自动给 P0 SFR 写全 1 ，也就是 P0.X 锁存器的 D 口都是高电平。那么 $\overline{\text{Q}}$ 就是低电平，从而 T1 基极低电平，处于截止。而由于控制端给低电平，经过与门后必然为低电平，从而 T0 也是截止。这样一来，P0 引脚就处于高阻状态，而所谓高阻状态实际上就是指依赖外部电平状态，不受内部电平控制。这样，P0 引脚就完全反映外部信号。接下来，若要读取引脚，那么下方的读引脚三态缓冲器就会打开，从而 P0 信号送达内部总线。


##### P0 作为通用 I/O 的情形

除了作为地址/数据复用总线外，P0 还可以作为通用 I/O 使用（**除 8031 外，因为 8031 只能靠外部 ROM ，因此这个口被地址/数据总线占据了，不能作为 I/O** ）。当它作为通用 I/O 时，**P0 SFR 不会自动写 1** ，且**控制端永远是低电平**。那么，T0 永远截止，MUX 永远指向 $\overline{\text{Q}}$ ，地址/数据信号永远不接入。这时如果要输出，那么输出的信号是从内部总线这里走，从 $\overline{\text{Q}}$ 出来时经过一次反相，控制 T1 。这里会遇到这样一个问题：
1. 如果输出的是低电平信号，那么 T1 接收高电平，导通，P0.X 引脚经过 T1 接地，表现为低电平，确实可以输出；
2. 如果输出的是高电平信号，T1 接收低电平，截止，而 T0 也是截止，P0.X 高阻，并不能输出高电平信号。为了解决这个问题，我们在把 P0 作为通用 I/O 且要输出时，需要**先在 P0.X 引脚上接一个上拉电阻**。这样，当 T1 和 T0 都截止时，P0.X 经过上拉电阻接电源，反映为高电平；且不会影响原本的低电平表达，因为当 T1 导通时 P0.X 距离接地总是只有一个 T1 管的压降，属于低电平范围。

当要输入时，由于锁存器中可能残留之前输入的低电平，而这会导致 T1 导通，将 P0.X 拉到地面。因此，我们必须手动先给 P0 写全 1 ，这个写入操作是为了给锁存器送高电平，从而让 T1 截止，P0.X 悬空从而可以完成读入。但是我们必须思考一个问题：前面我们为了解决输出的问题而在 P0.X 引脚上接了上拉电阻，这个上拉电阻是否会在 P0.X 读入低电平时造成影响？我们说不会，因为这个上拉电阻的驱动能力很弱。上拉电阻的阻值典型值为 $4.7\text{ k}\Omega$ ，对于一个 $5\text{ V}$ 电源而言，如果接入一个低电平，那么电流在 $1\text{ mA}$ 左右，这个电流很小，和外部输入比起来不足以把 P0 口电平拉到高电平状态。因此这时仍然是可以正常读入的。

读入操作仍然是通过读引脚完成，通过内部总线送入。




除了我们上面描述涉及到的部件以外，你可以注意到我们还没有提及那个“读锁存器”缓冲器。这个缓冲器从接线上看功能是把锁存器的 $\text{Q}$ 端又重新送回内部总线。它只有在一些“读 - 修改 - 写”类型的指令下才会启用。例如这个指令：
```
ANL  P0, A
```
这个指令的意思是作与逻辑运算（And Logic），并把运算结果存入第一个地址中。




根据上面的解释，现在你可以理解下面这种写法了：假设我们需要从 P0 口读外部输入到累加器中，则应当写
```
MOV  P0, #0FFH
MOV  A, P0
```
从 P0 口读外部输入，意味着我们是把它当成通用 I/O 口来用，因此在读取之前必须先给 P0 口写全 1 ，这个全 1 是写给锁存器的；然后才能从中读取数据放进累加器。如果不这么做，那么某些 P0.X 对应的锁存器可能残留之前用来输出的低电平，那么这时对应的 T1 就会导通。而一个导通的 T1 对于管脚来说相当于驱动能力极强的低电平电源（即接地），无论此时外部信号是什么，都会在读入时表现为 0 ，从而不能读到正确的信号。




### P1 口

P1 口即 P1.0 ~ P1.7 ，分布在标号 1 ~ 8 管脚。

和 P0 口相反，P1 口是四个 I/O 口中最简单的一个口。它没有数据/地址总线功能，只能作为 I/O 口使用。其电路结构如下图所示：

![[e51ed68082641e9b3249c3666385209a.jpg]]


锁存器部分电路结构和 P0 一样，区别在于 $\overline{\text{Q}}$ 外接直接就是一个 T ，没有 MUX 也没有 T0 。等于说当 P0 口工作在通用 I/O 情况下时的等效结构。

当 P1 要输出时，若从内部总线给高电平，此时 T 截止，P1.X 上拉，表现为高电平；若从内部总线给低电平，此时 T 导通，P1.X 接地，表现为低电平。

当 P1 要输入时，同样需要先给锁存器写全 1 ，此时 T 截止，P1.X 微弱上拉，但可以被外部驱动，从而通过读引脚可以读入 P1 数据。




### P2 口

P2 口即 P2.0 ~ P2.7 ，分布在管脚编号 21 ~ 28 上。

P2 口相比 P1 要相对复杂一些，但没有 P0 那么多功能。它可以作为通用 I/O 口，这时它的功能和 P1 完全相同；但同时也可以作为地址总线。这地址是指一个完整地址的**高 8 位**，即 A15 ~ A8 。低 8 位由 P0 负责。

![[dd14982c9dff15a5db10d13414a10919.jpg]]

当它作为地址线使用的时候，由于地址总是通过 CPU 发往外侧的，因此**只会输出地址，而不会输入地址**。输出地址的工作流程也和 P0 相似，通过控制线送一个高电平，此时 MUX 就会向右打，接通地址线，地址信号取反后送到 T ，再配合上拉电阻，即可让 P2.X 跟踪地址线信号。若不想作为地址线使用，那么就让控制端送低电平，从而 MUX 向左打，接通锁存器。不过要注意，由于这里的 T 前面多了一个非门，有一次反相，所以**接通锁存器的时候不是接在 $\overline{\text{Q}}$ 上，而是接在 $\text{Q}$ 上**，这样经过两次反相刚好和前面一致。

前面我们说，当 P0 作为地址/数据复用总线使用时，系统自动给 P0 SFR 写全 1 ，那是因为 P0 在作复用总线时仍然既可能输入也可能输出。但是，P2 在作为地址总线使用的时候只会输出，不需要输入，因此系统不会自动给 P2 SFR 写全 1 ，而是保持之前状态不变。



### P3 口

P3 口即 P3.0 ~ P3.7 ，分布在编号为 10 ~ 17 的管脚上。

P3 口作为通用 I/O 口使用时，工作原理仍然和 P1 相同，不再赘述；但它比较特殊的方面是它具备第二功能控制。

所谓第二功能，就是相当于键盘上的 shift 键；你可以看到本节开头的管脚分布图中 P3 系列端口很多都有额外的功能标注。

### 其他 I/O 管脚特性及注意点

当 P0 作为地址/数据总线使用时，每一位口线都可以驱动 8 个 LSTTL 门输入；P1 ~ P3 每一位口线只能驱动 4 个 LSTTL 门输入。

当 P0 口作为通用 I/O 口使用时，需要自己手动上拉电阻；P1 ~ P3 内置已经上拉电阻，所以作为 I/O 功能使用时不需要再上拉电阻。

地址总线的容量是 16 位，因此最多可以扩展 64KB 的外部程序存储器（即 ROM ）和最多 64KB 的外部数据存储器（即 RAM ）。

数据总线容量是 8 位，每次可以传递最大 0FFH 的数。

控制总线容量是 12 位，这种说法的意思是把 P3 的所有口线算上，再加上单独的 4 个控制管脚，总共 12 位。
