
本节内容在 MCS-51 中不太用得到，因此以一般家用笔记本为例简单说明：

低功耗工作方式主要分为两种，一种保留 RAM 而另一种不保留 RAM 。所谓保留 RAM 的低功耗运行，是指不断开 RAM 的电源，但停止时钟电路的工作。对于要求时序才能正常工作的计算机电路而言，当时序停止时相当于把整个电路中的状态全部冻结。这时虽然没有掉电，但计算机电路的主要功耗来源是**开关功耗**（操作各种晶体管改变状态的功耗）而不是**静态功耗**（上电维持运行的功耗），所以这时的功耗相比正常运行可以降低许多。

对于不保留 RAM 的情况，由于 RAM 一旦掉电就会丢失数据，所以一般笔记本都会在进入睡眠之前将 RAM 中的内容全部搬到硬盘中，也即虚拟内存。完成后再断电，让 RAM 中的内容丢失。重新唤醒时，需要先从硬盘中读入保存的 RAM 数据，然后才能开始工作。
