
### 转换时间和转换速率

完成一次转换需要的时间。这个值直接决定了 AD 的采样频率。通常，对于现代仪器，最差的一般也有 $100\text{ MHz}$ 级别的采样频率了。


### 分辨率

输出的数字量的位数。



### 采样保持器

采样保持器现在一般集成在 AD 中了。它的任务实际上和锁存器差不多——因为要在转换过程中维持输入量不变。只不过锁存器是指数字信号的概念，而采样保持器的任务是维持一个模拟量大小不变。



### 工作电压、基准电压

准确程度影响转换出的结果的漂移程度。





### 连接方式

先看用 P1 口的接法。

![[Pasted image 20260609085510.png]]

这里的 `P2.0` 用于发出开始转换信号，从而 AD 会读入一次模拟电压并开始转换数字量，低电平有效。完成后通过 EOC/End Of Conversion 提示主机可以取数，然后取出数字量。低电平有效。


现在根据上面的连接方式，要求采集 32 点，记录到 `60h ~ 7Fh` 位置中。那么这个程序总体上就是不断发出 start ，然后软件延时等待 eoc ，等到了就读一次然后继续 start ，用一个寄存器间接寻址控制写入头。

```
	mov    R0, #32         ; 计数器
	mov    R1, #60h        ; 间接寻址写入头
	mov    P1, #0FFh       ; 先写全高，读前准备
	setb   P2.0            ; 写高
	setb   P2.1            ; 写高
	
Loop:
	clr    P2.0            ; 发出开始信号
	lcall  Delay           ; 软件延时
	setb   P2.0            ; 开始信号低电平拉回
	
Wait:
	jb     P2.1, Wait      ; 等待 P2.1 低电平
	
	mov    A, P1           ; 读入结果
	mov    @R1, A          ; 存数
	inc    R1              ; 写入头后跳
	djnz   R0, Loop        ; 计数器自减
	
Delay:
	...
```

接下来我们要讲利用 P1 这组口的多个模拟量连接方法。这个实现方法是通过**模拟开关**。模拟开关是将多路模拟信号选择送到某几路上的器件。注意它不是译码器，而是选通。也就是说，输入和输出都是存在数值大小的模拟量，而不是高低电平。只有选通控制是高低电平。

![[Pasted image 20260609101058.png]]

这样，我们可以让多个模拟量先通过模拟开关再接入 A/D。


或者，使用标准的三总线扩展接法。

![[Pasted image 20260609105153.png|336]]

因为这是一种只读器件，所以只需要接上行。A/D 结果经过三态缓冲器 244 ，接到外部数据总线。缓冲器通过 /RD 和 /CSO 控制读使能和片选，另外仍然用 `P1.0` 和 `P1.1` 来控制启动和检查完成。

注意三总线扩展中，P0 和 P2 两个系列都被用于总线连接，而 P3 口有另外功能，因此这里收发转换信号只能通过 P1 来完成。

不过，start 信号其实可以通过 /WR 和 /CSO 的或信号来完成。那么这时，想要启动 AD 只需要向片外该机选通的地址中的随便哪一个写随便什么内容。因为写的内容会被缓冲器挡住，而我们需要的是“向片外写”这个动作来启动 AD 。

现在要求按照这个电路，设计一个测量 8 次电压，然后求平均值的程序。

```
;======== 采集部分 ==========

	mov    R0, #8        ; 计数器
	mov    R1, #60h      ; 间接寻址写入头
	mov    DPTR, #/cso   ; 选通作为扩展地址来源
	setb   P1.0          ; 写高准备
	setb   P1.1          ; 写高准备
	
Loop:
	clr    P1.1          ; start 写低
	setb   P1.1          ; start 回高

Wait:
	jb     P1.0, Wait    ; 等待 eoc 出现低电平
	movx   A, @DPTR      ; 取出数据
	mov    @R1, A        ; 写入位置
	inc    R1            ; 写入头后跳
	djnz   R0, Loop      ; 计数器自减

;======== 求均值部分 ==========

	mov    R7, #7        ; 除了第一个数之外再加 7 个数
	mov    R3, #0        ; 用于统计和的高八位值
	mov    A, 60H        ; 先把 60h 第一个数放进去
	mov    R0, #61H      ; 作为读入头使用
	
AddAG:
	add    A, @R0        ; 读一个数，作加法
	jnc    Next          ; 如果没有进位，那么去 Next
	inc    R3            ; 如果发生进位，那么高位值自增

Next:
	inc    R0            ; 读入头后跳
	djnz   R7, AddAG     ; 计数器自减，如果还没减到 0 就继续回去加
	mov    R2, A         ; 低位值存放到 R2
	mov    R0, #3        ; 求平均就是右移 3 次
	
Div8:
	clr    C             ; 先清零进位位，舍弃循环过来的位
	mov    A, R3         ; 取高八位
	rrc    A             ; 带进位位循环右移，相当于除以 2 
	mov    R3, A         ; 放回
	mov    A, R2         ; 取低八位(高低位有继承关系，所以不清除 C )
	rrc    A             ; 带进位位循环右移
	mov    R2, A         ; 放回
	djnz   R0, Div8      ; 计数器自减
```

![[Pasted image 20260609192101.png|501]]

这张图看起来挺简单的，就是多了一个片选。但是之前学 DA 的时候我们说实际上需要同步，因此这里我们也有点怀疑：图中这个原理图是否真的能用？

答案是能用。因为一次 AD 转换完成后，结果就全部在缓冲器上了，只要你的软件在开启下一次转换之前把数据按顺序取走，那么不会有任何问题。
