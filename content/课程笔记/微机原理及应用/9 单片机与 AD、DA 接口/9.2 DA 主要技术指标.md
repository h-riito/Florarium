
### 分辨率

数字量存在最小的变化单位，因此转换后的模拟量也存在最小分辨单位。显然，接受 $n$ 位二进制数输入的转换器，它的分辨率就是$$\frac{\text{最大转换值}}{2^n}$$我们把这个值记作 $1\text{ LSB}$ ，代表输入的最低一位代表多大的模拟量值。例如若满量程为 $10\text{ V}$ ，那么如果接受 $n=10$ ，则这时$$1\text{ LSB}=9.77\text{ mV}$$


### 偏移误差

理想情况下，数字量输入为 0 时，模拟量输出也应该是 0 。但是由于 DA 的一些硬件条件和直流问题，通常会存在一个偏移。



### 线性度

理想情况下，数字量增大多少，模拟量也应该成比例地增大多少。但实际测量每个点的输出结果，它会和理论线之间存在一定差距。这个差距中误差最大的那个记作线性度。一般要求小于 $\pm 0.5\text{ LSB}$ 。


### 精度

精度是综合线性度、偏移误差、参考电压等等因素后得到的综合测量指标，即测量结果与理论值之间的最大偏差。

参考电压是指一个由专门设计的、相对精密的来源提供的电压。它的精准程度也会影响输出结果。


### 转换速度

即每秒钟 DA 转换的最大次数。


### 温度灵敏度/温漂

器件在相同输入情况下，随温度不同输出变化的幅度。




### 8 位 D/A 接口设计


> [!NOTE] 例题
> 假定现在 8051 的 P1 口连接了 D/A 转换器，请设计输出频率可调的锯齿波发生器。
> 
> ---
> 
> 锯齿波是指这样的波：从低电平到高电平的线性变化，且每次达到最高点时跳变为最低点。因此，这个程序设计非常简单：
> 
> ```
> 		mov    A, #0
> Loop:   mov    P1, A
> 		lcall  Delay
> 		inc    A
> 		ljmp   Loop
> 		
> Delay:  ...
> ```
> 
> 只需要先给 `A` 送一个初值，然后不断“延时 + 累加 + 送 P1 端口”即可。频率通过你的延时具体实现来控制。因为 `A` 中的值在累加达到最大值 `0FFh` 后会自动重新变为 `0` 。


> [!NOTE] 例题
> 硬件同上例，但要求输出三角波，试调整程序。
> 
> ---
> 
> 三角波是要求上升和下降呈现对称的变化过程的波形。它的实现程序总体和前面相同，区别就是区分上升和下降过程。
> 
> ```
> 		mov    A, #0
> Up:     mov    P1, A
> 		lcall  Delay
> 		inc    A
> 		jnz    Up
> Down:   dec    A
> 		mov    P1, A
> 		lcall  Delay
> 		jnz    Down
> 		sjmp   Up
> 		
> Delay:  ...
> ```
> 
> 我们的检查办法是，对于上升或者下降过程，累加到变为 `0` 后就代表当前阶段结束了，进入另一个阶段即可。


以上这种接法称为**直接接法**。但是通常我们不会这样做，除非确定这整个系统就只有 D/A 这一个外设，不然直接接 P1 口比较浪费。这里是这样的：
1. 如果你的系统只要接 D/A 这一个外设，那你用直接接法当然没毛病，而且理论上你想接哪接哪，要是你在软件上愿意折腾，你把 8 根线接到不同的 `Pn` 上都行。
2. 默认这种时候接 P1 是因为它“开箱即用”，并且通常来说不耽误事。因为：如果你接 `P0` ，那么 `P0` 在不作为外部总线的情况下是没有上拉电阻的，你还得手动上拉一个排阻；如果接 `P2` ，那 `P2` 自己有个任务是高 8 位外部地址线，换句话说有自己的任务；如果接 `P3` ， `P3` 每个口都有副业，什么串口收发，什么外部中断，什么定时器中断，什么外部读写选通，这些功能全部被占用。综合来看接 `P1` 最低冲突。
3. 如果你的系统要接多种外设，那么应该**规范到 I/O 扩展的统一接法上来**，即全部走外部总线，并且和其它外设之间沟通好片选占用，把自己作为一个只写不读的寄存器来用。也就是说，模仿前面学 I/O 扩展时的接法， `P0+373` 和 `P2` 拉出 `A0~A15` 当外部地址线，同时也从 `P0` 拉出数据线 `D0~D7` ，然后和可能存在的其它外部设备之间确定片选规则，从高位地址线中拉出几根来片选。
4. 本机不需要知道自己下一句外部写命令会写给谁，这由硬件控制。本机只负责写的时候 `movx  @DPTR, A` ，通过高位地址来反映实际的片选。

所谓的任意函数发生器是指，对于任意函数，如果考虑数字信号，那么它可以被归结为一个有限长的映射表。因此，这个函数的发生，就相当于指定一个周期内任意时刻的值，存储为一张表，然后不断遍历这张表上的值作为输出即可。从而

```
DAC_ADDR   EQU    0FE00H           ; /CS0 对应的存储器地址

Start:     mov    R0, #0D0H        ; 循环次数 = 表长度
           mov    R1, #0           ; R1 = 表索引

Loop:      mov    DPTR, #Tab       ; DPTR -> 表首地址
           mov    A, R1            ; A = 当前索引
           movc   A, @A+DPTR       ; 读 Tab[R1]
           mov    DPTR, #DAC_ADDR  ; 选通 D/A
           movx   @DPTR, A         ; 输出
           inc    R1               ; 索引+1
           lcall  Delay            ; 延时
           djnz   R0, Loop
           sjmp   Start

Delay:     ...                     ; 软件延时子程序

Tab:       db     ...              ; 若干字节波形数据
```
