
来看封装好的产品：ADC0809 .

![[Pasted image 20260609192336.png]]

这个芯片的设计允许我们用地址线来自然地完成模拟量通道的选择：
1. ABC 三根地址线通过 ALE 锁存使能放进锁存器，然后用来控制模拟开关选通。
2. 我们可以通过控制 ABC 这个地址来直接选定要观察哪路模拟量输入。
3. 这个 ALE 就是锁存使能。

右边的三态输出缓存器下面有 OE ，这个是 Output Enable 。如果用三总线解法，那么就跟 /RD 接就行了，不过这里是高电平有效，那么需要一个非门。

还有一个时钟 CLK 。这个时钟也接 ALE 就行，因为我们说 51 每个机器周期都会有固定的 ALE 动作，因此可以用来当作驱动 AD 的时钟。同时，因为这个型号的 AD 是**逐次逼近型**的，而我们知道逐次逼近型并不要求时钟的准确周期性，只要能够在固定时间内发出固定数量的高低电平就可以，因此可以使用 ALE 。相较而言，对于双积分型，由于存在定时积分的测时操作，因此必须要一个精准的时钟来完成。

回顾三总线 IO 拓展的标准流程：
1. P0 口数据和地址分离，用 373 完成。
2. 从 373 出来的是地址，地址接地址，连接到 0809 的 ABC 选通地址。
3. 同时从 P0 直接出来的是数据线，数据接数据，接 0809 的输出端。
4. P2.7 就是 /CSO ，作为片选，要用的时候置低就行。
5. 向外写就是启动，从外读动作就自动让 0809 输出使能。
6. EOC 接到你想要获取完成信号的任意口，这里 P1 还空着，一般接到 P1 口上。
7. 主机的 ALE 经过一个 D 触发器当作 0809 的时钟，这里让 ALE 接入 D 触发器的时钟，然后让 Q 非直接接 D ，这样就不停翻转。这样做是为了二分频，这种接法让 Q 输出时钟频率变成 ALE 的一半。对于 12MHz 晶振，ALE 输出是 1/6 ，即 2MHz ，这对 0809 来说频率偏高，不太推荐，所以改成 1MHz 。0809 的推荐工作频率在 640KHz 以下。


下面看延时等待方式程序编写：

```
Main:
	mov    R1, #data         ; 作为写入头，存数据区首地址
	mov    DPTR, #7FF8h      ; 等同于 P2.7=0 且 P0.0=P0.1=P0.2=0
	                         ; 即片选 + ABC 通道选择 IN0
	mov    R7, #08h          ; 希望采 8 个通道，作为计数器
	
Loop:
	movx   @DPTR, A          ; 做出向外写操作，即启动 AD
	mov    R6, #25           ; 给 R6 作为软件延时计数器
	
Delay:
	nop
	nop
	nop                      ; =3     周期
	djnz   R6, Delay         ; =5(+2) 周期
;=========================================
                             ; 共计 125 周期
	
	movx   A, @DPTR          ; 读入结果
	mov    @R1, A            ; 放在写入头位置
	inc    DPTR              ; 选择下一个通道( ABC 恰好在最低 3 位)
	inc    R1                ; 写入头后跳
	djnz   R7, Loop          ; 通道计数器自减
	
	...
```

我们看到这里没有使用 EOC 来作为读动作的条件，而是硬性延时 125 周期就直接读了。为什么可以这样做？这是因为硬件特性。 0809 的手册中规定了其单次 AD 转换最长时间不会超过 $116 \,\mu\text{s}$ ，这里一个周期是 1 微秒，125 微秒延时超过了最长时间，所以必定可以读取。因此你允许软件等待时间足够长，那么你可以不接 EOC 。如果你急着用，那就要靠 EOC 来提示读取。


使用中断方式编写如下。把 EOC 连接到外部中断 /INT1 ，这样可以让外部中断事件自动完成。

```
INT1:
	setb    IT1             ; 中断触发方式为边沿触发
	setb    EA              ; 中断总使能
	setb    EX1             ; 外部中断 1 使能
	mov     DPTR, #7FF8h    ; 选通、片选
	mov     A, #00h         ; 清空 A (不必要)
	movx    @DPTR, A        ; 外部写动作
	...

; 中断服务	
PINT1:
	mov     DPTR, #7FF8h    ; 选通、片选
	movx    A, @DPTR        ; 外部读动作
	mov     30h, A          ; 存数
	mov     A, #00h         ; 清空 A
	movx    @DPTR, A        ; 外部写动作
	reti
```
