
### 简单程序

顺序执行程序通常最为简单，并且是构成复杂程序的基础。

 

这里的 12 ~ 14 行是取出当前进位值的常用做法。你可能会觉得写法有点奇怪。不过，考虑到 Cy 是一个位，位不能直接赋值给字节，因此这样做是最简便的方法了。

美元符号代表自身地址，所以第 16 行的意思就是原地踏步，相当于完成任务后待机。注意，**原地踏步不代表程序接下来不再会发生任何事情**，因为还有一个可能打断这一情况的因素，那就是中断，例如计时器中断。如果发生中断，那么 PC 会重新跳到需要执行中断程序的位置。


> [!NOTE] 2
> 现在在内部 RAM 的 `20H` 单元中存放了一个 8 位无符号数。将这个数转化成 3 位 BCD 码，并将这个 BCD 码高 4 位存放到` FIRST `单元，低 8 位存放到 `SECOND` 单元。
> 
> ---
> 
> 我们知道，一个 8 位无符号数最多到 255 。因此，它转化成 BCD 码后，高 4 位就是它的百位，低 8 位就是它的十位和个位。那么，我们可以先想办法分离出每一位对应的二进制值，而由于对于 1 位十进制数来说，它的二进制码就是 BCD 码，因此将其放入指定位置即可。
> 
> 例如
> 
> ```
> ORG     1000H
> 
> HBCD:  
> 
> MOV     A, 20H     ; 取数
> MOV     B, #64H    ; 设置除数为 100
> DIV     AB         ; 除法。除法后，百位作为商放在 A 中，余数放在 B 中
> 
> MOV     FIRST, A   ; 百位填入 FIRST 中
> MOV     A, B       ; 将余数放到被除数
> MOV     B, #0AH    ; 设置除数为 10
> DIV     AB         ; 除法。除法后，十位在 A 中，个位在 B 中
> 
> SWAP    A          ; 把 A 的十位交换到高 4 位位置
> ORL     A, B       ; 将 A 和 B 做或运算，由于和 0 或的结果是本身，这可以合并值
> MOV     SECOND, A  ; 将十位和个位放进 SECOND 中
> 
> SJMP    $
> END
> ```
> 

值得注意的是， `DIV   AB` 这条指令由于只有这一种写法，因此其中的 A 和 B 都是寄存器寻址。而 `MOV   A, B` 这条指令中只有 A 是被固定的，因此 B 实际上会以地址的方式写入，也就是直接寻址，而**不是寄存器寻址**。


> [!NOTE] 3
> 一个压缩 BCD 码（即在一个字节中存放两个 BCD 码的形式）放在内部 RAM 的 `20H` 单元，将其拆开，并将各自表示的数字分别转换成 ASCII 码。然后将原来高 4 位的数字对应的 ASCII 码放到 `21H` ，低 4 位的数字对应的 ASCII 码放到 `22H` 。
> 
> ---
> 
> 这个问题有多种解决办法。
> 
> 首先我们需要知道的是，由于 0~9 数字对应的 BCD 码就是它们的数值的二进制码，因此直接拆开后高低 4 位就代表各自的数值。然后，根据 ASCII 的排表特点，要将一个数字转换成对应的字符，只需要将数值加上 `#30H` 即可。
> 
> 注意到， `#30H` 这个值是 `0011 0000` ，因此进一步地，我们可以直接将需要存储的 `21H` 和 `22H` 单元设置为这个数，然后将低 4 位填写进去即可。
> 
> ```
> ORG    1000H
> 
> MOV    R0, #22H   ; 先把低四位要填的地址放进 R0 ，一会儿用于间接寻址
> MOV    @R0, #0    ; 先给 22H 写全零
> MOV    A, 20H     ; 把待处理内容放进 A
> XCHD   A, @R0     ; 把 A 的低四位和对应位置的低四位交换，即可实现放入
> ORL    22H, #30H  ; 再把那个位置和 #30H 作或运算，写入高位
> SWAP   A          ; 交换 A 的高低位，开始处理高四位
> ORL    A, #30H    ; 先把高位写好
> MOV    21H, A     ; 再把整个数一起放到位置上
> 
> SJMP   $
> END
> ```

这个程序中，需要注意的是由于我们要借助借位位来判断大小，因此使用前应当手动清空 Cy 的值，即 `CLR  C` ，避免出现问题。

你可以注意到，对于这种根据数值大小来确定分支跳转的程序，由于 `CJNE` 和 `JC` 组合时“相等情形”的不对称性，如果每次都要自己考虑跳转是否正确以及把每个分支写在哪，会非常麻烦。为此，我们建议直接将这种分支结构固定下来，每次写分支时就像代码补全一样直接填空即可：

```
;============================================
;  判断 A 与立即数区间 [L,R] 大小关系的分支模板
;============================================


;==================================以下负责跳转控制

	CJNE  A, L, Check1     ;先检查左端点
	SJMP  Inside           ;相等情况属于内部，直接跳转
Check1:
	JC    Left_side        ;不相等时，如果发生借位，说明在左侧
	
	CJNE  A, R, Check2     ;如果到这里那么说明大于L，需要检查右端点
	SJMP  Inside           ;相等情况属于内部，直接跳转
Check2:
	JNC   Right_side       ;如果没有发生借位，说明在右侧
	
	;如果到这里，说明对左边有借位对右边没借位，那么就是内部

;==================================以下只需填写各种情况的具体操作	
	
Inside:

	;填写在内部的操作
	
	SJMP  Exit_branch
	
Left_side:

	;填写在左侧的操作

	SJMP  Exit_branch
	
Right_side:

	;填写在右侧的操作
	
	SJMP  Exit_branch

;=================================以下离开分支

Exit_branch:
	
```

套用这种模板时，**注意检查 Cy 值的变化**。

下面是对单个数的比较关系模板：

```
;============================================
;  判断 A 与立即数 X 大小关系的分支模板
;============================================
	
	CJNE   A, X, Not_equal
	
	;若没有跳转，说明相等。此处填写相等时需要处理的内容
	
	SJMP   Exit_branch
	
Not_equal:
	JC     Less_than
	
	;此处为不相等且不发生借位，说明在右边。填写大于 X 时需要处理的内容
	
	SJMP   Exit_branch
	
Less_than:
	
	;此处为不相等且发生借位，说明在左边。填写小于 X 时需要处理的内容
	
Exit_branch:

```

上面这种写法中，如果等于情况和大于情况相同，那么可以去掉第 7 和第 9 行，这样顺序执行会将它们合并。如果等于情况和小于情况相同，则你需要在去掉第 7 和第 9 行的情况下再把 X 改成 X+1 ，因为能被顺序合并的总是等于和大于情况，因此你需要先这么做，然后把判定标准向右平移一格，这样就实现相等情况和小于情况合并的效果了。



下面来看另一种跳转：**散转表**。这种跳转常常用于模拟 switch-case 跳转方式。它的通常用于不同状态的跳转，例如 `R3` 中存放了当前的状态值，从 `0` 到 `3` 不等。现在需要根据不同状态值进行不同的跳转，我们可以利用这种状态值来对应到一串连续存储的跳转指令，再根据那些跳转指令到达实际执行程序的位置。例如：

```
	MOV   A, R3
	CLR   C
	SUBB  A, #4
	JNC   Exit_Error         ;先作减法看一下状态值是否合法，防止意外跳转
	
	MOV   A, R3              ;取状态值
	MOV   B, #3              ;乘以 3
	MUL   AB                 ;乘 3 是因为后面每一条 LJMP 占 3 字节
	
	MOV   DPTR, #Jump_Table  ;将散转表地址（内部）给 DPTR
	JMP   @A+DPTR            ;将这个地址加上缩放后的 A 值作为跳转位置
	
Jump_Table:
	LJMP  Case_0             ;跳转后，根据缩放后的值的不同，会跳到这里的 4 条
	LJMP  Case_1             ;指令之一，从而进一步前往下面对应的指令
	LJMP  Case_2
	LJMP  Case_3
	
CASE_0:
	...
	SJMP  Done
	
CASE_1:
	...
	SJMP  Done
	
CASE_2:
	...
	SJMP  Done
	
CASE_3:
	...
	SJMP  Done
	
Exit_Error:                  ;错误状态情形可以填写一些还原寄存器状态的指令
	...
	
Done:
	...
```

如果你用 `AJMP` 完成，那么就应当把缩放改成乘以 2 。注意乘以 2 一般是用移位操作实现，即 `RL  A` 。

这里的 `JMP  @A+DPTR` 是专有写法，只有这一条可以这样写。



### 循环程序

循环程序主要由三个部分组成：
1. **初始化部分**：在进入循环前，对循环变量以及其它变量赋初值，做准备工作。这也隐含了：任何循环程序都不允许在循环外通过跳转指令直接进入循环体，必须先通过初始化部分才能进入。
2. **循环体部分**：循环体除了重复执行部分以外，还应该有修改循环变量的控制部分，以及跳出检查部分。
3. **结束部分**：跳出循环后执行的存放和分析操作。注意这一步是可选的，即从内到外的跳出是允许跳过这一部分的。


> [!NOTE] 1
> 在内部 RAM 的 `30H~4FH` 单元中一共存放了 32 个无符号数。要求计算这 32 个的数的和（可以确保小于 65536 ）并将结果放在 `51H 50H` 中。
> 
> ---
> 
> 计算 32 个数的和，需要执行 31 次加法，并且没有中途退出的条件。
> 
> 由于待加数的存储是连续的，因此寻址时最好的办法是间接寻址。
> 
> 由于参与运算的数都是单字节的，因此我们只需要更新 `50H` 中的内容。只有在这一次发生进位的时候，才需要更新 `51H` ，且更新时总是只加 1 。
> 
> 可能的代码如下：
> 
> ```
> 	ORG   0200H
> Start:
> 	MOV   R7, #31          ;R7用来存放循环变量，注意是十进制数
> 	MOV   R3, #0           ;R3用来临时存放高位值
> 	MOV   A, 30H           ;先把第一个数放入 A
> 	MOV   R0, #31H         ;把第一个要加的数的地址放入R0
> 	
> Loop:
> 	ADD   A, @R0           ;计算加法
> 	JNC   Next             ;如果没有进位就跳过改变R3逻辑
> 	INC   R3               ;否则就让R3自增
> 
> Next:
> 	INC   R0               ;让R0指向下一个数
> 	DJNZ  R7, Loop         ;循环变量更新，返回循环开头
> 	MOV   51H, R3          ;完成后，写入对应位置
> 	MOV   50H, A
> 	SJMP  $
> 	
> 	END
> ```



> [!NOTE] 2
> 在外部 RAM 的 `BLOCK` 单元开始，有一个长数据块。数据块的长度存在 `LEN` 单元，你需要：将数据块中正数、负数、零的个数存入 `PCOUNT` `MCOUNT` `ZCOUNT` 单元。
> 
> ---
> 
> 容易想到，这是一个定长循环，且没有中途跳出情况。并且每个循环处理时需要进行分支。
> 
> 分支的判断标准是正负或零，因此我们可以将数先放进 A ，然后看 `ACC.7` 是不是 1 ，如果是那就是负数；如果不是，那么可以用 `JNZ` 指令判断是否为零。并且，在分支结束后，把长度自增，然后进入下一循环即可。

### 子程序

我们已经接触过了子程序的写法：

```
LCALL/ACALL   Tag

Tag:
	...
	
	RET
```

子程序和 `LJMP` 与 `AJMP` 的区别在于前者会将 PC 跳出位置入栈，而后者不会。因此，如果你写了 `LJMP` 而又写了 `RET` ，程序会跳转回随机位置，取决于你当前的栈内情况。

需要注意子程序中的寄存器维护问题。不像高级语言，变量名只作用于当前层级及其内部，汇编程序中无论什么层级都共用同一个寄存器。因此，如果你需要在子程序中修改一些寄存器的值，而在主程序中又要使用原来的值的话，你需要自己维护堆栈，先把寄存器值压入栈中进行保护，并在子程序返回后第一时间弹出还原。
