
### 软件延时写法

假设晶振频率 $12\text{ MHz}$ ，那么由于机器频率是晶振频率的 $1/12$ ，从而一个机器周期需要 $1 \,\mu\text{s}$ 。如果我们想要用软件延时写一个 $2\text{ ms}$ 的等待，那么可以这样写双层循环：

```
DELAY_2MS:
     MOV R6, #10       ; (1us) 外层循环
D1:  MOV R7, #98       ; (1us) 内层循环初始值
D2:  DJNZ R7, D2       ; (2us * 98 = 196us)
     DJNZ R6, D1       ; (2us * 10 = 20us)
     RET               ; (2us)
```

这是因为 `DJNZ` 是一条双周期指令，每次执行它会消耗 $2\text{ }\mu s$ 。因此，我们让整个程序最内层执行 $98$ 次，外层执行 $10$ 次，这时，算上循环跳转、赋值等操作的延时，总体上接近 $2\text{ ms}$ 。

对于更长的时间，则可以用更多层循环实现。

```
DELAY_1S:
     MOV R5, #10       ; (1us) 第一层
D3:  MOV R6, #200      ; (1us) 第二层
D4:  MOV R7, #248      ; (1us) 第三层
D5:  DJNZ R7, D5       ; (2us * 248 = 496us)
     DJNZ R6, D4       ; (2us * 200 = 400us)
     DJNZ R5, D3       ; (2us * 10 = 20us)
     RET
```

但这种写法的问题是，考虑到各种跳转的时间，通常你需要细致地考虑才能把耗时算准，而且这种软件延时会导致 CPU 不能干别的事情，一旦你在计时过程中需要并发处理其他事情，就很难将其写在循环中。
