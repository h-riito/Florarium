这是一个以 Markdown 为唯一内容源的个人知识主页原型。

它目前遵循三条原则：

1. **内容先于装修。** 页面设计服务于阅读与重新发现，而不是遮盖内容不足。
2. **链接先于分类。** 文件夹提供大致位置，链接表达实际关系。
3. **公开必须是主动行为。** 未明确标记的笔记默认不发布。

技术上，它使用 Quartz 生成静态网站，并计划托管在 GitHub Pages。详细链路见 [[guides/publishing-workflow|发布流程]]。
